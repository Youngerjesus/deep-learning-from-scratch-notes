### 행렬과 비교했을 때 텐서의 정의는 어떻게 되는가? 

텐서는 사실상 행렬과 비슷한 다차원 배열임. 근데 텐서는 여기에다가 수학적인 성질들이 좀 들어가있음. 자동 미분 (역전파시에 활용), 브로드캐스트, 연산 후 내적 추적 등 

### 퍼셉트론이란? 

딥러닝 신경망을 구현하는데 사용되는 기본적인 알고리즘임. 

다수의 입력을 받아서 하나의 신호를 출력으로 내놓는 것으로 논리회로 게이트 (AND, OR, NAND) 와 유사하다. 

퍼셉트론에서의 출력은 임계값을 뛰어 넘으면 1 그렇지 않으면 0이 된다는 점 (딥러닝 활성화 함수의 step funciton 과 같음)이 있음. 

그리고 입력 신호만 있는게 아니라 이런 입력을 보다 강하게 만들어주는 가중치와 입력의 여부와 상관없이 뉴런의 값이 활성화 되느냐 안되느냐를 결정함. (편향인 b에 큰 수인 -99999 를 넣는다고 생각해봐라. 입력이 커도 활성화가 안되게 만들어줄 수 있음.)


### 퍼셉트론의 한계는 무엇인가? 

퍼셉트르론은 그래프로 표현했을 경우 직선으로 표현하고 직선의 영역으로 나눌 수 있는 것만 구현할 수 있음. 

퍼셉트로으로는 XOR 게이트를 구현할 수 없다. XOR 게이트를 그래프로 표현해보면 (0,0) 과 (1,1) 은 포함시키면 안되지만 (0,1), (1,0) 은 포함시켜야 함. (즉 비선형으로 휘어야 하는 건 구현이 안됨)

그래서 퍼셉트론으로 간단한 기능은 구현할 수 있지만 모든 기능은 구현할 수 없음. 

하지만 사실 이런 퍼셉트론은 다층으로 쌓는다면 XOR 게이트를 구현할 수 있음. (한계를 극복하는 방법임. 이것 뿐 아니라 계산기와 같은 좀 더 복잡한 것도 구현할 수 있다) 

다층 퍼셉트론은 비선형 함수를 구현할 수 있는거임. 

### 그럼 신경망과 다층 퍼셉트론의 차이는? 

퍼셉트론은 활성화 여부를 결정하기 위해 step function 을 사용했지만 현재의 딥러닝에서의 활성화 함수로는 ReLU 등 다양하게 있음. 

그리고 퍼셉트론은 가중치와 편향을 인간이 수동으로 결정했다면 인공 신경망은 데이터를 기반으로 이런 파라미터를 자동으로 결정해줌. 


### Sigmoid 활성화 함수에서 ReLU 로 가게된 이유는? 

Sigmoid 함수에는 결정적인 단점이 있음. 입력이 크거나 작은 경우에는 기울기가 0에 가까워져 역전파 과정시 앞 쪽까지 전달이 안됨. 

계산 효율성 측면에서도 ReLU 가 더 압도적 


### 현재의 딥러닝에서는 활성화 함수로 뭐씀? 

ReLU 
- 계산이 간단하고 미분값이 충분해서 사용 
- 죽은 ReLU 문제가 있음. 출력 값이 음수가 되면 그레디언트 값도 0이되서 학습이 진행되지 않음. 

Leaky ReLU 
- 음수 영역에서도 작은 기울기를 부여해서 죽은 ReLU 문제를 완화 

GeLU(Gaussian Error Linear Unit) 
- Transformer 계열 모델들(BERT, GPT 등)에서 기본 활성화로 사용됨 
- 입력값이 클수록 1에 가까워지고 작을수록 0에 가까워짐. 부드러운 곡선 형태라 미세한 정보 흐름 전달이 가능 

### 활성화 함수로 비선형 함수를 사용해야하는 이유? 

선형 함수를 사용하면 똑같은 선형 함수만 나와서 복잡한 패턴을 찾는 함수를 만들기 어려움 

일반적으로 층을 깊게할수록 복잡한 패턴이 만들어지는데 층을 길게 해도 큰 의미가 없어짐.
